> 프로젝트 규칙: [`CLAUDE.md`](../CLAUDE.md) · 지금까지의 과정과 주의할 점: [`docs/제작과정.md`](제작과정.md)

## 0. 처음 한 번만: 내 컴퓨터 준비

| 설치할 것 | 받는 곳 | 확인 명령 |
|---|---|---|
| Node.js (LTS 버전) | https://nodejs.org | `node --version` |
| Git | https://git-scm.com | `git --version` |
| GitHub 계정 | https://github.com | 저장소 주인에게 초대받기 |


## 1. 만들 게임 고르기

`src/games/` 안의 폴더 하나가 게임 하나다. 기획서는 `docs/games/<게임ID>.md`.

| 게임ID | 제목 | 장치 | 기획서 |
|---|---|---|---|
| `body-rebel` | 몸이 말을 안 들어! | 📷 카메라 (전신) | ✅ 완성 — 참고용 |
| `stack-sense` | 눈치껏 쌓아라 | 📷 카메라 (손) | `docs/games/stack-sense.md` |
| `fruit-bell` | 땡! 과일벨 | 🥁 리듬·악기 | `docs/games/fruit-bell.md` |
| `beat-bungeo` | 박자 붕어빵 | 🥁 리듬·악기 | `docs/games/beat-bungeo.md` |
| `dont-say` | 말하지 말랬잖아! | 🎤 마이크 | `docs/games/dont-say.md` |
| `ghost-store` | 귀신도 편의점에 옵니다 | 🥽 VR·MR | `docs/games/ghost-store.md` |
| `gaze-ball` | 눈으로 공을 굴려라 | 👁️ 시선·햅틱 | `docs/games/gaze-ball.md` |

> 다른 조원과 같은 게임을 하지 않도록, **시작 전에 조 단톡방에 "○○ 게임 맡을게요"라고 알린다.**
> 표에 없는 완전히 새 게임이라면 먼저 기획서(`docs/games/<새ID>.md`)를 써서 공유한다.

## 3. 게임 만들기

### 3-1. 폴더 구성

```
src/games/<게임ID>/
├─ meta.ts     ← 이미 있음. 카드·소개 페이지 정보 (사이트가 자동으로 찾아 등록)
├─ index.ts    ← 새로 만들기. 실제 게임
├─ config.ts   ← 새로 만들기. 밸런스 수치 (시간, 점수, 판정 범위…)
└─ rules.ts    ← (선택) 규칙 계산만 따로 — 화면 없이 시험하기 쉬움
```

**가장 빠른 시작: 견본 복사.** `src/games/_template/`이 아주 작지만 완전히 동작하는 견본 게임이다.
`_template`의 `index.ts`, `config.ts`를 내 게임 폴더로 복사해서 고쳐 나가면 된다.
(`meta.ts`는 내 폴더에 이미 있으니 복사하지 않는다)

### 3-2. 게임 코드의 형식 (`index.ts`)

```ts
import type { GameModule } from '../types';

const game: GameModule<'camera-pose'> = {
  setup: 'camera-pose',                     // 어떤 장치 준비 화면을 거칠지
  modes: [                                  // 소개 페이지의 시작 버튼들
    { players: 1, label: '👤 혼자 하기' },
    { players: 2, label: '👥 둘이 대결' },
  ],
  start(container, input, { players, onFinish }) {
    // container 안에 게임 화면을 그리고, input(어댑터)의 이벤트로 입력을 받는다.
    // 게임이 끝나면:
    //   onFinish({ scores: [점수], details: ['한 줄 설명'], summary: ['요약'], log: 기록 });
    return {
      destroy() { /* 루프 멈추기, 이벤트 떼기, 화면 비우기 */ },
    };
  },
};
export default game;
```

### 3-3. 사이트에 연결 (`meta.ts`)

내 폴더의 `meta.ts`에서 두 군데만 바꾼다.

```ts
  status: 'ready',                       // 'wip' → 'ready'
  load: () => import('./index'),         // 맨 아래 주석(//) 풀기
```

이제 허브에서 카드를 누르면 소개 → 장치 준비 → 내 게임 → 결과 화면으로 이어진다.
**허브·주소·결과 화면 코드는 건드릴 필요 없다.**

### 3-4. 꼭 지킬 규칙 (CLAUDE.md 요약)

- **원작 이름·그림·소리 금지.** 게임 이름은 기획서의 가제 사용. 그래픽은 도형·이모지·직접 만든 것만.
- **외부 파일 다운로드 금지** (이미지·소리·폰트). 효과음은 `src/shared/sfx.ts`처럼 코드로 만든다.
- **숫자는 `config.ts`에.** 코드 중간에 `3000`, `0.15` 같은 값을 직접 쓰지 않는다. (` 키 디버그 패널에서 실시간 조정 가능)
- **장치는 어댑터로만.** 게임에서 `getUserMedia` 같은 장치 API를 직접 부르지 않는다. `input`으로 받은 것만 쓴다.
- **인식 상태를 항상 화면에** (뼈대·손 위치·음량 그래프 등). 입력이 끊기면 자동 일시정지.
- **나갈 때 정리.** `destroy()`에서 루프·이벤트를 모두 멈춘다.
- 주석·화면 문구는 한국어.

### 3-5. 내 게임에 필요한 장치가 아직 없다면

지금 준비된 장치는 **📷 카메라 전신 포즈(`camera-pose`)** 하나다.
손 추적·마이크·MIDI·VR 등이 필요하면 아래를 새로 만들어야 하는데, **여러 게임이 같이 쓰는 공용 코드**라서 먼저 조원들과 상의한다.

1. 어댑터: `src/input/<장치>.ts` — `start()`, `stop()`, 이벤트, 정규화된 값
2. 준비 화면: `src/setup/<장치>-setup.ts` — 권한 요청 → 입력 확인 → 시작 버튼
3. 연결: `src/games/types.ts`의 `SetupInputs`에 한 줄, `src/games/play.ts`의 `SETUPS`에 한 줄

참고할 기존 코드: `src/input/camera-pose.ts`, `src/setup/camera-setup.ts`

## 4. 확인하기

```bash
npx tsc
npm run build
```

두 명령이 오류 없이 끝나야 한다.

- `npm run dev`로 띄워 허브 → 내 게임 카드 → 소개 → 준비 화면 → 게임 → 결과까지 직접 해 본다.
- 데스크톱 폭과 좁은 창에서 화면이 깨지지 않는지 본다.
- 실제 장치로 확인 못 한 부분은 "사용자 확인 필요"로 적어 둔다.

## 5. 올리기

```bash
git add .
git commit -m "stack-sense: 블록 집기·놓기 구현"
git push -u origin game/stack-sense
```

GitHub 저장소 페이지에 뜨는 **Compare & pull request** 버튼으로 PR(합치기 요청)을 만든다.
저장소 주인이 확인하고 `main`에 합치면 사이트에 반영된다.

마지막으로 [`docs/제작과정.md`](제작과정.md)의 **"게임별 기록"**에 내 게임 기록을 양식대로 추가한다
(무엇을 만들었는지, 기획서에 없어서 정한 것, 남은 일).

## 7. 자주 막히는 곳

| 증상 | 해결 |
|---|---|
| 내 게임 카드가 허브에 안 보임 | `meta.ts`의 `id`가 폴더 이름과 같은지 (브라우저 콘솔에 경고가 뜬다). 폴더 이름이 `_`로 시작하면 등록 안 됨 |
| 카드를 누르면 "점검 중"만 뜸 | `meta.ts`의 `status: 'ready'`와 `load` 주석을 풀었는지 |
| 카메라가 안 켜짐 | 크롬·엣지에서 열었는지, 카메라 권한을 허용했는지, 다른 프로그램(줌 등)이 카메라를 쓰는지 |
| 개발 서버 화면이 이상함 | 새로고침. 안 되면 `npm run dev`를 껐다 다시 켜기 |
| `git push` 거절됨 | 저장소에 초대받았는지, `git pull`로 최신 내용을 먼저 받았는지 |
