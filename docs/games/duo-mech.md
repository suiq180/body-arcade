# 합체 로봇 조종석 (`duo-mech`)

> 하드웨어: 🕹️ 아케이드 스틱 (2인용 레버 2개 + 버튼 6개씩) | 원래 조작: 없음 (새 기획) | 플레이 시간: 한 판 약 5분 | 인원: 2인 협동 (1인 + AI 가능)

## 1. 한 줄 소개
로봇 한 대를 둘이 나눠 탄다. **P1은 다리(이동·점프·대시)**, **P2는 팔(조준·무기·방패)**. 보스의 공격을 피하고 막으면서 둘이 타이밍을 맞추면 합동 공격이 터지는 협동 보스전 액션.

## 2. 콘셉트에서 가져온 것 / 새로 만든 것
- 가져온 것(일반적인 장르 구조): 2D 횡스크롤 보스전, 보스 패턴 단계, 체력·방어
- 새로 만든 것:
  - 조종을 **이동 담당 / 공격 담당**으로 나눠, 혼자서는 피하면서 쏠 수 없게 만든다
  - 합동 공격: P1의 이동 동작(점프·대시·착지) 순간에 P2가 쏘면 위력이 커진다
  - 로봇·보스·효과음은 전부 도형과 Web Audio 합성으로 직접 만든다 (컨트롤러에 인쇄된 그림·캐릭터와 무관)

## 3. 하드웨어
- 2인용 아케이드 스틱. 보통 USB로 **게임패드 2개**로 잡힌다 (Gamepad API). 키보드로 잡히는 기기도 있어 키 배정 화면에서 둘 다 받는다
- 장치 분류: 새 탭 `arcade` (🕹️ 아케이드 스틱) — `giant-steps`와 같은 어댑터·준비 화면을 쓴다
- 아케이드 스틱이 없으면 게임패드 2개 또는 키보드 하나로 대체

## 4. 조작
| | P1 다리 | P2 팔 |
|---|---|---|
| 레버 | ← → 이동, ↓ 웅크리기 | 8방향 조준 (누르고 있는 방향으로 팔이 돌아감) |
| 버튼 1 | 점프 | 레이저 (연사) |
| 버튼 2 | 대시 (짧은 무적) | 미사일 (충전 3초, 유도) |
| 버튼 3 | 버티기 (밀려나지 않음) | 방패 (앞쪽 공격 막기, 에너지 소모) |
| 버튼 4 | — | 집게 (보스가 던진 물건 잡아 되던지기) |
| 버튼 5·6 | 합동 기술 신호 (둘 다 누르면 발동) | 합동 기술 신호 |
| START | 일시정지 | 일시정지 |

## 5. 규칙
- 로봇 체력 하나를 둘이 같이 쓴다. 0이 되면 다운 → 둘이 합동 신호 버튼을 동시에 누르면 1회 부활 (판당 1번)
- 에너지 게이지: 방패·대시·미사일이 같은 에너지를 나눠 쓴다 → 누가 에너지를 쓸지 말로 상의해야 한다
- **합동 공격**: P1 점프 최고점 / 대시 직후 / 착지 순간에 P2가 쏘면 2배 피해 + 콤보
- **합동 기술**: 둘이 버튼 5·6을 0.3초 안에 같이 누르면 발동 (콤보 게이지가 찼을 때만). 로봇이 돌진 + 회전 베기
- 보스를 쓰러뜨리면 클리어. 점수 = 남은 체력 + 걸린 시간 + 합동 공격 수

### 보스 공격 패턴 (보스 공통 부품)
| 패턴 | 피하는 방법 | 담당 |
|---|---|---|
| 낮은 탄 | 점프 | P1 |
| 높은 탄 | 웅크리기 | P1 |
| 정면 광선 | 방패 | P2 |
| 내려찍기 | 대시로 빠지기 | P1 |
| 던지기 | 집게로 잡아 되던지기 | P2 |
| 끌어당기기 | 버티기 + 방패 동시 | 둘 다 |

## 6. 진행·난이도
| 스테이지 | 보스 | 특징 |
|---|---|---|
| 1 | 연습용 표적 로봇 | 패턴 하나씩, 화면에 "P1 점프!" 같은 안내 |
| 2 | 바퀴 탱크 | 낮은 탄·높은 탄·내려찍기 |
| 3 | 공중 포대 | 위쪽 조준 필요, 던지기 |
| 4 | 거대 기계 거미 | 패턴 2개 동시, 끌어당기기 |
| 5 | 최종 보스 | 체력 3단계, 단계마다 패턴 추가 |
- 보스 체력이 줄수록 공격 속도 증가

## 7. 화면 구성
- 가운데: 옆에서 본 로봇과 보스 (한 화면 고정, 스크롤 없음)
- 위: 로봇 체력 · 에너지 · 콤보 게이지 / 보스 체력
- 아래 왼쪽: P1 조종석 표시 (레버 방향·버튼), 아래 오른쪽: P2 조종석 표시 — 다리·팔 색과 같은 색
- 조준선: P2 팔 방향으로 점선

## 8. 피드백
- 로봇 다리는 P1 색(주황), 팔은 P2 색(청록)으로 칠해서 누가 무엇을 맡는지 바로 보이게
- 합동 공격: 탄이 커지며 "합동!" 문구 + 화면 번쩍
- 피격: 피격 방향 표시 + 짧은 화면 흔들림. 담당자 쪽 조종석 표시가 빨갛게 (예: 낮은 탄에 맞으면 P1 쪽)
- 보스 공격 예고: 0.6초 전 경고 표시 (패턴마다 다른 모양·소리)

## 9. 예외 처리
- **컨트롤러 연결이 끊기면** 자동 일시정지 + 어느 쪽인지 안내 (기획서 8.4)
- 1인 + AI 모드: 사람이 다리 또는 팔 중 하나를 고르고, 나머지는 AI가 맡음 (AI는 담당 패턴만 반응)
- 방패·대시 에너지가 0일 때 누르면 "에너지 부족" 소리만 나고 아무 일도 없음

```ts
energyRegenPerSec: 12
shieldCostPerSec: 30

reviveOnce: true

bossHp: [60, 150, 200, 260, 400]
```

## 11. 완료 조건
- [ ] 아케이드 스틱(게임패드 2개 / 키보드로 잡히는 경우 모두)을 P1(다리)·P2(팔)로 배정하고 저장할 수 있다
- [ ] P1은 이동 계열만, P2는 조준·무기 계열만 조작된다
- [ ] 에너지 공유, 합동 공격(2배 피해), 합동 기술(동시 입력), 1회 부활이 동작한다
- [ ] 보스 패턴 6종이 예고 후 발동하고, 담당에 맞는 방법으로만 피할 수 있다
- [ ] 스테이지 5개와 최종 보스 3단계가 동작한다
- [ ] 1인 + AI 모드에서 AI가 맡은 쪽 역할을 수행한다
- [ ] 컨트롤러 연결이 끊기면 자동 일시정지된다
- [ ] 플레이 기록(패턴별 피격 횟수와 담당자, 합동 공격 수, 에너지 사용 비율 P1/P2, 스테이지별 시간)을 내보낼 수 있다 → 패턴 난이도·에너지 밸런싱용
- [ ] (사용자 확인 필요) 실제 아케이드 스틱으로 두 사람이 했을 때 역할 분담이 자연스러운지

## 12. 정한 것 (2026-11-17, 사용자 결정)
- 스테이지 사이 **부품 강화 상점** 넣음 (강화 장갑·큰 배터리·발전기·레이저 렌즈·미사일 탄두, 각 3단계 — 값은 `config.ts`)
- 역할 교대는 **강제하지 않고 선택**: 스테이지 사이 화면에서 "역할 바꾸기"를 고를 수 있음 (1인 + AI 모드는 내 역할 선택)
- 화면: **Three.js 3D** (판정은 2D로 하고 3D는 그리기만)
