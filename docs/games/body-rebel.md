# 몸이 말을 안 들어! (`body-rebel`)

> 하드웨어: 📷 카메라 모션 인식 (웹캠 전신 포즈) | 원래 조작: 버튼 + 웹캠 | 플레이 시간: 한 판 약 3분 | 인원: 1~2인 (2인은 한 카메라에 나란히)

## 1. 한 줄 소개
화면 지시와 **반대로 몸을 움직여야** 하는 청개구리 반응 게임. 규칙이 수시로 뒤집혀서 머리와 몸이 따로 논다.

## 2. 원래 콘셉트에서 가져온 것 / 바꾼 것
- 가져온 것: 말과 반대 행동하기, 라운드 규칙 변경, 버튼 미션·동작 미션, 방해 아이템, 2인 대결, 라운드 결과·최종 결과
- 바꾼 것:
  - 물리 버튼을 없애고 **"버튼 미션"을 화면 속 가상 버튼을 몸으로 치는 미션**으로 변경 (화면 좌·중·우 위쪽에 빨강·파랑·노랑 버튼 → 해당 위치로 손을 뻗어 터치)
  - 모든 입력이 몸동작 하나로 통일되어 장치가 웹캠 하나면 된다

## 3. 조작 (인식 가능한 동작 목록)
| 동작ID | 동작 |
|---|---|
| `raise-left` / `raise-right` | 왼손 / 오른손 들기 |
| `raise-both` | 두 손 머리 위로 |
| `touch-red` / `touch-blue` / `touch-yellow` | 화면 위 해당 색 버튼 위치에 손 뻗기 |
| `squat` | 앉기 |
| `jump` | 제자리 점프 |
| `lean-left` / `lean-right` | 몸 기울이기 |
| `freeze` | 3초간 움직이지 않기 |
- 좌우는 **플레이어 기준**(화면은 거울 모드)

## 4. 규칙
- 매 문제마다 지시문이 뜨고, 제한 시간(5초→점점 짧아짐) 안에 **현재 규칙에 맞는 동작**을 해야 함
- 규칙 종류 (라운드마다 바뀌고, 라운드 중간에 "규칙 변경!" 이벤트로 뒤집히기도 함)
  | 규칙 | 지시 "오른손 들어" 일 때 정답 |
  |---|---|
  | 정직 | 오른손 |
  | 반대 | 왼손 |
  | 거짓말쟁이 색 | 지시 글자의 **색**이 말하는 버튼을 쳐야 함 (글자는 "빨강", 색은 파랑 → 파랑) |
  | 가만히 | 지시가 빨간 글씨면 아무것도 하지 않기 |
- 동작 미션: "두 손 머리 위로 3초 유지" 같은 유지형. 진행 게이지 표시
- 성공 +100, 가장 빨리 성공하면 +50 (2인), 틀린 동작 0점
- 5라운드, 각 6문제

### 방해 아이템 (2인 모드)
- 3문제 연속 성공 시 아이템 1개. 두 손을 X자로 교차하면 사용
| 아이템 | 효과 |
|---|---|
| 안개 | 상대 쪽 화면 3초 흐리게 |
| 거울 | 상대 좌우 판정 2문제 동안 반전 |
| 빨리빨리 | 상대 제한 시간 절반 |

## 5. 진행·난이도
| 라운드 | 제한 시간 | 쓰는 규칙 |
|---|---|---|
| 1 | 5초 | 정직 → 반대 (연습) |
| 2 | 4.5초 | 반대 |
| 3 | 4초 | 반대 + 가만히 |
| 4 | 3.5초 | 거짓말쟁이 색 + 규칙 변경 1회 |
| 5 | 3초 | 무작위, 규칙 변경 2회 |

## 6. 화면 구성
- 위쪽 가운데: 지시 말풍선, 현재 규칙 아이콘
- 위쪽 좌·중·우: 색 버튼 3개 (치는 대상)
- 화면 전체: 거울 모드 카메라 + 뼈대 표시 (2인은 좌/우 반씩 나눠 P1·P2 색 뼈대)
- 오른쪽: 인식 상태 미니 인형 (지금 인식된 동작 이름 표시)

## 7. 피드백
- 성공: 뼈대가 초록으로 번쩍 + 효과음
- 실패: 뼈대 빨강 + "앗!" + 어떤 동작이 정답이었는지 0.8초 표시
- 규칙 변경: 화면 흔들림 + 경고음 + 2초 멈춤 후 진행

## 8. 예외 처리
- 시작 전 "두 팔 벌리고 서 주세요" 전신 인식 확인 (어깨~무릎 보여야 시작)
- 2인일 때 두 사람이 화면 중앙선을 넘으면 경고
- 한 문제에서 여러 동작이 감지되면 **처음으로 확정된 동작**만 판정
- 동작은 0.3초 유지되어야 확정 (스쳐 지나가는 자세 무시)

## 10. 완료 조건
- [ ] 동작 11종이 각각 구분되어 인식된다 (인식 상태 인형에 표시)
- [ ] 규칙 4종이 정답 판정에 맞게 적용된다
- [ ] 규칙 변경 이벤트가 라운드 중에 발생한다
- [ ] 2인 모드에서 좌/우 플레이어가 따로 판정된다
- [ ] 방해 아이템 3종이 상대에게만 적용된다
- [ ] 동작 0.3초 유지 확정 방식으로 오인식이 줄어든다
- [ ] 플레이 기록(문제별 규칙, 정답 동작, 반응 시간, 오답 동작)을 내보낼 수 있다 → 제한 시간·규칙 난이도 밸런싱용
- [ ] (사용자 확인 필요) 방 안 2~3m 거리에서 전신 인식이 된다

## 11. 미정 사항
- 지시를 음성으로도 읽어 줄지 (소리 지시 + 반대 행동)
- 4인 팀전 지원 여부
