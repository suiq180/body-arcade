# 땡! 과일벨 (`fruit-bell`)

> 하드웨어: 🥁 리듬·악기 컨트롤러 (전자 드럼 패드 / MIDI 패드) | 원래 조작: 모바일 터치 | 플레이 시간: 한 곡 약 2분 | 인원: 1~4인 (같은 화면)

## 1. 한 줄 소개
박자에 맞춰 카드가 한 장씩 뒤집히고, 같은 과일이 정확히 5개가 되는 순간 **드럼 패드를 쳐서 종을 울리는** 눈치·순발력 리듬게임.

## 2. 원래 콘셉트에서 가져온 것 / 바꾼 것
- 가져온 것: 카드를 뒤집어 보이는 과일 개수를 합산, 같은 과일 합이 5가 되면 종 치기, 가장 빠른 사람이 득점
- 바꾼 것:
  - 플레이어가 카드를 뒤집지 않고, **음악 박자마다 자동으로 카드가 뒤집힌다** (곡 = 한 판)
  - 종 = 드럼 패드. 플레이어마다 패드 1개씩 배정
  - 박자에 맞춰 치면 보너스 → 순발력 + 리듬감 둘 다 필요
- 상표 주의: 원작 이름·카드·종 디자인은 쓰지 않는다

## 3. 하드웨어
- 1순위: USB MIDI 드럼 패드 / 전자 드럼 (Web MIDI, 패드별 노트 번호로 플레이어 구분)
- 2순위: 태고형 북 컨트롤러·게임패드 (Gamepad API)
- 시작 전 "자기 패드를 한 번씩 쳐 주세요"로 플레이어-패드 연결 (최대 4명)

## 4. 조작
| 동작 | 입력 | 결과 |
|---|---|---|
| 종 치기 | 자기 패드 치기 | 지금 상태가 정답이면 득점, 아니면 감점 |
| 세게 치기 | 벨로시티 100 이상 | 정답일 때 "땡!" 특수 연출 + 보너스 +1 |

## 5. 규칙
- 테이블에 플레이어 수만큼(1인 모드는 4자리) 카드 자리가 있고, 박자마다 한 자리씩 순서대로 새 카드가 덮어씌워짐
- 각 카드에는 과일 1종류가 1~5개 그려져 있음 (과일 4종)
- 보이는 카드 기준, 어떤 과일의 합이 **정확히 5**가 되면 종 칠 기회
- 정답 시 가장 먼저 친 사람 +3점, 박자에 맞춰(±80ms) 쳤으면 +1 추가
- 오답(5가 아닌데 침)은 -2점, 그 박자 동안 해당 플레이어 패드 잠김
- 1인 모드: AI 상대 3명(반응 속도 다름)과 경쟁

## 6. 진행·난이도
| 곡 | BPM | 특징 |
|---|---|---|
| 1 | 80 | 과일 2종만, 정답 기회 표시(힌트 빛) |
| 2 | 100 | 과일 4종 |
| 3 | 120 | **함정 카드**: 과일 수가 그림이 아닌 숫자로만 표시 |
| 4 | 140 | 반박자 연속 구간, 카드 2장이 동시에 넘어감 |
- 정답 기회 빈도는 곡당 일정 범위로 생성기가 조절 (너무 드물거나 잦지 않게)

## 7. 화면 구성
- 가운데: 원형 테이블 위 카드 자리들, 중앙에 큰 종
- 테이블 가장자리: 플레이어별 색·점수
- 아래: 박자 표시 줄 (다음 카드가 넘어갈 타이밍)
- 맨 위: 곡 진행률

## 8. 피드백
- 정답: 종이 크게 흔들리며 소리 + 친 플레이어 색으로 화면 번쩍
- 오답: 패드 주인 자리 위에 X, 잠김 표시
- 박자 맞춤 보너스: "ON BEAT!" 문구

## 9. 예외 처리
- **지연 보정 필수**: 처음 실행 시 메트로놈에 맞춰 8번 치기 → 평균 오차를 오프셋으로 저장 (공통 리듬 보정 화면)
- 동시 입력: 같은 프레임이면 타임스탬프(MIDI 이벤트 시각)로 비교
- MIDI 장치가 없으면 게임패드 버튼으로 대체 안내

## 10. 밸런스 수치 (`config.ts` 초기값)
```ts
targetCount: 5
fruitKinds: 4
countRange: [1, 5]
onBeatWindowMs: 80
scoreCorrect: 3
scoreOnBeat: 1
scoreHardHit: 1
hardHitVelocity: 100
penaltyWrong: -2
lockBeats: 1
chanceRatePerSong: [0.15, 0.25]   // 박자 중 정답 기회 비율
aiReactionMs: [450, 650, 900]
songs: [ {bpm:80, kinds:2, hint:true}, {bpm:100, kinds:4}, {bpm:120, kinds:4, numberCards:0.3}, {bpm:140, kinds:4, doubleFlip:true} ]
```

## 11. 완료 조건
- [ ] MIDI 패드를 치면 플레이어별로 구분되어 인식된다
- [ ] 카드가 BPM에 맞춰 넘어가고, 과일 합 계산이 정확하다
- [ ] 정답·오답·박자 보너스·세게 치기 보너스가 규칙대로 계산된다
- [ ] 오답 시 해당 플레이어만 1박 잠긴다
- [ ] 지연 보정 값이 판정에 반영된다
- [ ] 1인 모드 AI가 서로 다른 속도로 반응한다
- [ ] 플레이 기록(정답 기회마다 플레이어별 반응 시간, 오답 시점)을 내보낼 수 있다 → AI 반응 속도·BPM 밸런싱용
- [ ] (사용자 확인 필요) 실제 패드로 쳤을 때 지연이 느껴지지 않는다

## 12. 미정 사항
- 곡 제작 방식 (직접 작곡 / 저작권 없는 음원)
- 패드 1개를 2명이 나눠 쓰는 경우(좌/우 패드) 지원 여부
