# 눈치껏 쌓아라 (`stack-sense`)

> 하드웨어: 📷 카메라 모션 인식 (웹캠 손 추적) | 원래 조작: 모바일 터치 | 플레이 시간: 한 판 약 5분 | 인원: 2~6인 (한 화면 번갈아 하기)

## 1. 한 줄 소개
차례가 오면 **허공에서 블록을 손으로 집어** 탑 위에 살며시 내려놓는다. 손이 떨리면 블록도 떨린다. 탑을 무너뜨린 사람이 탈락하는 심리전 쌓기 게임.

## 2. 원래 콘셉트에서 가져온 것 / 바꾼 것
- 가져온 것: 순서대로 블록 쌓기, 무너뜨리면 라운드 탈락, 여러 라운드 점수제, 코인으로 아이템 구매, 배신자 모드·스페셜 모드, 한 판 5분
- 바꾼 것:
  - 터치 드래그 → **손으로 집고(핀치) 옮기고 놓기**. 놓는 순간의 손 속도가 블록에 그대로 전달된다 → 살살 놓는 섬세함이 실력
  - 손목을 돌리면 블록이 회전
  - 한 대의 웹캠 앞에서 차례대로 플레이 (온라인 없음)

## 3. 조작
| 동작 | 손 상태 | 결과 |
|---|---|---|
| 블록 고르기 | 손 펴고 화면 왼쪽 블록 선반 위로 | 선반 블록 강조 |
| 집기 | 핀치 | 블록이 손을 따라옴 (물리 영향 없음) |
| 회전 | 핀치 상태에서 손목 돌리기 | 블록 회전 (15° 단위로 스냅) |
| 놓기 | 손 펴기 | 그 순간의 손 속도를 가진 채 블록이 물리 상태로 전환 |
| 아이템 사용 | 주먹 1초 | 보유 아이템 사용 |

## 4. 규칙
- 차례마다 블록 1개를 30초 안에 탑 위에 올려야 함. 시간 초과 = 무작위 위치에 자동 낙하
- 놓은 뒤 3초 동안 탑이 버티면 성공. 무너지면(블록 3개 이상 바닥에 떨어짐) 그 사람 라운드 탈락
- 마지막까지 남은 사람이 라운드 승리. 성공한 층 수만큼 코인 획득
- 라운드 사이 상점: 코인으로 아이템 구매

### 아이템
| 이름 | 효과 |
|---|---|
| 접착제 | 다음 내 블록이 아래 블록에 고정됨 |
| 바람 | 다음 사람 차례에 옆바람 3초 |
| 미끄럼 | 다음 사람 블록이 얼음 재질 (마찰 감소) |
| 블록 빼기 | 탑에서 블록 하나를 제거 (무너질 위험 감수) |

### 모드
- 일반전: 기본 규칙
- 배신자 모드: 한 명이 몰래 "탑을 정확히 N층에서 무너뜨리기" 임무를 받음 (시작 시 화면을 가리고 개인에게만 보여 줌). 성공하면 배신자 단독 승리
- 스페셜 모드: 라운드마다 특수 블록(공, 삼각형, 긴 막대)과 미션("5층 넘기기") 등장

## 5. 진행·난이도
- 층이 올라갈수록 블록 모양이 어려워짐 (네모 → 긴 막대 → 삼각형·원)
- 라운드 3부터 탑이 아주 천천히 흔들리는 "지진" 효과

## 6. 화면 구성
- 가운데: 탑 (2D 물리, 측면 시점)
- 왼쪽: 블록 선반, 오른쪽: 플레이어 순서와 코인
- 위: "OO의 차례!" + 남은 시간
- 손 커서 + 오른쪽 아래 웹캠 미리보기

## 7. 피드백
- 집기: 블록 테두리 빛남
- 위험 감지(탑 기울기 일정 이상): 탑 주변 붉은 테두리 + 째깍 소리
- 붕괴: 느린 화면 연출 + "와르르!"

## 8. 예외 처리
- 손 추적이 끊기면 집은 블록은 그 자리에 멈춤(놓기로 처리하지 않음) + 타이머 정지
- 놓을 때 손 속도 상한을 둬서 추적 튐 때문에 블록이 날아가지 않게
- 한 화면에 손이 여러 개 잡히면 가장 가까운(큰) 손만 사용

## 9. 밸런스 수치 (`config.ts` 초기값)
```ts
turnTimeSec: 30
settleCheckSec: 3
collapseFallenBlocks: 3
releaseVelocityScale: 0.6 // 손 속도가 블록에 전달되는 비율
releaseVelocityMax: 2.0
rotateSnapDeg: 15
handSmoothing: 0.35
coinPerFloor: 1
itemPrice: { glue: 3, wind: 4, ice: 4, remove: 5 }
windForce: 0.8
quakeFromRound: 3
quakeAmplitude: 0.004
roundsPerGame: 5
```

## 10. 완료 조건
- [ ] 핀치로 블록을 집고, 손목 회전으로 돌리고, 손을 펴서 놓을 수 있다
- [ ] 놓는 순간 손 속도가 블록에 전달된다 (살살 놓으면 안정, 던지면 튕김)
- [ ] 무너짐 판정과 라운드 탈락이 정확하다
- [ ] 코인·상점·아이템 4종이 동작한다
- [ ] 일반전·배신자·스페셜 모드를 고를 수 있다
- [ ] 손 추적이 끊겨도 블록이 엉뚱하게 날아가지 않는다
- [ ] 플레이 기록(차례별 놓는 속도, 놓은 위치, 붕괴 층수, 아이템 사용)을 내보낼 수 있다 → 아이템 가격·속도 계수 밸런싱용
- [ ] (사용자 확인 필요) 2~3명이 번갈아 해도 손 인식이 매번 잘 잡힌다

## 11. 미정 사항
- 2D 측면 vs 3D 시점
- 배신자 임무를 개인에게 보여 주는 방법 (폰 QR로 따로 보여 주기 등)
