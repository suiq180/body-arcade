# 하드웨어 전환 게임 기획 — 전체 개요

원래 모바일·버튼 조작으로 구상된 게임 7종을, 각각 **하나의 하드웨어 종류**로만 조작하는 게임으로 바꾼 기획 모음이다.
각 게임 상세는 같은 폴더의 개별 문서를 따른다. Claude Code 프로젝트에서는 `docs/games/`에 넣어 사용한다.

## 배정표

| # | 게임ID | 제목 | 원래 조작 | 바뀐 하드웨어 | 배정 이유 |
|---|---|---|---|---|---|
| 1 | `fruit-bell` | 땡! 과일벨 | 모바일 터치 (종 누르기) | 🥁 리듬·악기 (드럼 패드) | 종 치기 = 패드 치기. 카드가 박자에 맞춰 넘어가면 리듬게임이 된다 |
| 2 | `gaze-ball` | 눈으로 공을 굴려라 | 웹캠 얼굴 거리 | 👁️ 시선 추적·햅틱 조끼 | 보는 방향으로 조향, 노면·위험을 몸으로 느낀다 |
| 3 | `stack-sense` | 눈치껏 쌓아라 | 모바일 터치 | 📷 카메라 모션 (손 추적) | 손 떨림까지 그대로 반영되는 진짜 쌓기의 긴장감 |
| 4 | `body-rebel` | 몸이 말을 안 들어! | 버튼 + 웹캠 | 📷 카메라 모션 (전신 포즈) | 버튼을 없애고 전부 몸동작으로 통일 |
| 5 | `ghost-store` | 귀신도 편의점에 옵니다 | 화면 버튼 3개 | 🥽 VR·MR 헤드셋 | 손님을 직접 가까이서 관찰하는 공포 몰입감 |
| 6 | `dont-say` | 말하지 말랬잖아! | 버튼 + 웹캠 | 🎤 마이크 | 장치마다 다른 목소리 조작(크게·높게·조용히·단어) |
| 7 | `beat-bungeo` | 박자 붕어빵 | 조이스틱 + 버튼 | 🥁 리듬·악기 (MIDI 키보드·드럼 패드) | 붓기·뒤집기·포장을 박자에 맞춰 연주하듯 |

분류별 개수: 리듬·악기 2 / 카메라 모션 2 / 마이크 1 / VR·MR 1 / 시선·햅틱 1

## 공통 주의사항

- **'할리갈리'는 등록 상표**라서 게임명·화면 어디에도 쓰지 않는다. 규칙(같은 과일 5개면 종 치기)은 참고 가능. 카드·종 디자인도 새로 만든다.
- 나머지 6종은 자체 콘셉트이므로 제목을 그대로 가제로 쓴다.
- 이미지 시안 속 캐릭터·사진은 콘셉트 참고용. 실제 게임 그래픽은 직접 제작한다.

## 플랫폼 메모

| 하드웨어 | 브라우저(사이트) 구현 | 비고 |
|---|---|---|
| 리듬·악기 | ⭕ Web MIDI, Gamepad API | 크롬·엣지 권장 |
| 카메라 모션 | ⭕ MediaPipe (Hand / Pose) | |
| 마이크 | ⭕ Web Audio, Web Speech | 음성 인식은 크롬 계열 |
| VR·MR | ⭕ WebXR (+ Three.js) | 콘텐츠가 많은 `ghost-store`는 유니티 빌드도 검토 |
| 시선 추적·햅틱 조끼 | ❌ 전용 장비는 브라우저 접근 불가 | **유니티 데스크톱 빌드** (Tobii + bHaptics SDK) 권장. 사이트에는 웹캠 시선 + 패드 진동 체험판 |

## 권장 제작 순서

1. `body-rebel` — 카메라 포즈 인식 공통 어댑터를 여기서 만든다
2. `stack-sense` — 손 추적 + 2D 물리
3. `fruit-bell` — MIDI/패드 입력 + 리듬 지연 보정 화면을 여기서 만든다
4. `beat-bungeo` — 3번의 리듬 기반 재사용
5. `dont-say` — 마이크 어댑터
6. `ghost-store` — VR (헤드셋 필요)
7. `gaze-ball` — 유니티 + 전용 장비 (장비 확보 후)
