# 눈으로 공을 굴려라 (`gaze-ball`)

> 하드웨어: 👁️ 시선 추적 + 햅틱 조끼 | 원래 조작: 웹캠 얼굴 거리 | 플레이 시간: 코스당 약 1~2분 | 인원: 1인 (기록 경쟁)

## 1. 한 줄 소개
공은 **내가 바라보는 쪽으로** 굴러가고, 노면의 진동·장애물 충돌·점프 착지를 **조끼로 몸에 느끼며** 결승선까지 가는 타임어택 레이싱.

## 2. 원래 콘셉트에서 가져온 것 / 바꾼 것
- 가져온 것: 섬 위 코스를 굴러가는 공, 직선·장애물·점프대·결승 구간, 타이머 기록 경쟁, PERFECT/GOOD/MISS 판정
- 바꾼 것:
  - 얼굴 거리 → **시선**. 화면에서 보는 위치가 곧 조향(좌우)과 속도(위쪽을 볼수록 가속)
  - 판정 대상이 "얼굴 거리 정확도"에서 **"구간별 목표 라인을 얼마나 정확히 따라갔나"**로
  - 햅틱 조끼로 몸에 정보 전달: 화면을 보지 않아도 공 상태를 알 수 있게

## 3. 하드웨어와 플랫폼
- 정식판: **유니티 데스크톱 빌드** + Tobii 계열 아이트래커 SDK + bHaptics 조끼 SDK (브라우저에서는 두 장비 모두 직접 접근 불가)
- 사이트 체험판: 웹캠 시선 추정(MediaPipe 홍채) + 게임패드 진동으로 햅틱 대체. 정확도가 낮으므로 코스 폭을 넓힌 "쉬운 코스"만 제공
- 시선·햅틱 입출력은 어댑터 인터페이스로 분리해서 두 판이 같은 게임 로직을 공유

## 4. 조작
| 동작 | 입력 | 결과 |
|---|---|---|
| 조향 | 시선 좌우 위치 | 공이 그쪽으로 기움 (화면 중앙 = 직진) |
| 가속 | 시선을 화면 위쪽(먼 곳)으로 | 속도 증가 |
| 감속 | 시선을 화면 아래(공 근처)로 | 속도 감소 |
| 점프 | 점프대 위에서 **눈 두 번 깜빡임** | 일정 속도 이상이면 점프 |
- 시선은 떨림이 많으므로 강한 스무딩 + 데드존 적용

## 5. 햅틱 조끼 출력
| 상황 | 조끼 패턴 |
|---|---|
| 공이 길 왼쪽 가장자리에 가까움 | 왼쪽 옆구리 약한 진동, 가까울수록 강해짐 (오른쪽도 동일) |
| 장애물 충돌 | 정면 가슴 강한 펄스 1회 |
| 점프 착지 | 등→배 방향으로 퍼지는 진동 |
| 가속 구간 진입 | 아래→위로 올라가는 물결 |
| 코인 획득 | 짧은 톡 |
| 결승 | 전체 진동 3회 |

## 6. 규칙
- 코스 4구간: 직선 → 장애물 → 점프대 → 결승 (원래 콘셉트의 코스 구성 유지)
- 장애물 충돌 시 속도 50% 감소, 길 밖으로 떨어지면 마지막 체크포인트 + 3초 패널티
- 구간마다 바닥에 빛나는 **목표 라인**: 공이 라인과 가까울수록 PERFECT
  - PERFECT: 라인 ±5% 이내 / GOOD: ±15% / MISS: 그 이상
- 최종 기록 = 시간 − (PERFECT 구간 보너스)

## 7. 진행·난이도
| 코스 | 길 폭 | 특징 |
|---|---|---|
| 1 | 넓음 | 직선 위주, 장애물 적음 |
| 2 | 보통 | 좌우 굽은 길 + 움직이는 장애물 |
| 3 | 좁음 | 연속 점프대, 가장자리 난간 없음 |

## 8. 화면 구성
- 3인칭 공 뒤 시점
- 시선 커서(작은 반투명 원) 상시 표시
- 왼쪽 위 타이머, 오른쪽 위 속도 게이지, 구간 판정 팝업

## 9. 예외 처리
- 시작 전 시선 보정(9점)과 조끼 연결 테스트(부위별 진동 확인)
- 시선 데이터가 0.5초 이상 끊기면 공 자동 감속 + 일시정지 안내
- 조끼가 없으면 화면 가장자리 붉은 표시로 대체 (햅틱 없이도 플레이 가능)
- 깜빡임 점프는 점프대 위에서만 인식 (평소 깜빡임 오작동 방지)

## 10. 밸런스 수치 (`config.ts` 초기값)
```ts
gazeSmoothing: 0.8
steerDeadzone: 0.08
steerStrength: 1.0
speed: { min: 4, base: 8, max: 16 }   // m/s
accelZoneY: 0.35          // 화면 위쪽 35% 바라보면 가속
brakeZoneY: 0.75
jumpMinSpeed: 10
doubleBlinkWindowMs: 600
collisionSpeedLoss: 0.5
fallPenaltySec: 3
judge: { perfect: 0.05, good: 0.15 }
perfectBonusSec: 0.5
haptic: { edgeStartRatio: 0.7, maxIntensity: 1.0, collisionMs: 200 }
```

## 11. 완료 조건
- [ ] 시선 좌우로 조향, 상하로 가감속이 된다
- [ ] 점프대 위에서만 이중 깜빡임 점프가 된다
- [ ] 햅틱 패턴 6종이 상황에 맞게 출력된다
- [ ] 조끼 없이도 시각 대체 표시로 플레이할 수 있다
- [ ] 구간별 PERFECT/GOOD/MISS 판정과 최종 기록 계산이 맞다
- [ ] 시선·햅틱이 어댑터로 분리되어 웹 체험판과 유니티판이 같은 로직을 쓴다
- [ ] 플레이 기록(구간별 목표 라인 오차, 충돌 위치, 시선 끊김 횟수)을 내보낼 수 있다
- [ ] (사용자 확인 필요) 아이트래커로 코스 2를 완주할 수 있다
- [ ] (사용자 확인 필요) 진동 세기가 불쾌하지 않다

## 12. 미정 사항
- 아이트래커·조끼 장비 확보 방법 (학교 장비 대여 등)
- 고스트(내 최고 기록 공) 표시 여부
