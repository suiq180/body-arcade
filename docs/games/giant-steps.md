# 두 다리 거인 (`giant-steps`)

> 하드웨어: 🕹️ 아케이드 스틱 (2인용 레버 2개 + 버튼 6개씩) | 원래 조작: 없음 (새 기획) | 플레이 시간: 한 판 약 3분 | 인원: 2인 협동 (1인 연습 가능)

## 1. 한 줄 소개
거인 한 명의 **왼다리는 P1, 오른다리는 P2**가 맡는다. 둘이 번갈아 레버를 밀어야 앞으로 걷고, 박자가 어긋나면 거인이 기우뚱하다 쿵 넘어진다. 둘이 호흡을 맞춰 결승선까지 가는 협동 웃음 게임.

## 2. 콘셉트에서 가져온 것 / 새로 만든 것
- 가져온 것(일반적인 놀이 구조): 이인삼각처럼 둘이 발을 맞춰 걷기, 넘어지면 다시 일어나기, 장애물 코스 완주
- 새로 만든 것:
  - 다리 하나 = 플레이어 하나. 레버 하나로 다리 하나를 직접 움직인다
  - 균형 게이지: 같은 다리를 연속으로 쓰거나 너무 서두르면 기울어진다. 버튼으로 팔을 흔들어 균형을 되찾는다
  - 화면 그래픽·소리는 모두 도형과 Web Audio 합성으로 직접 만든다 (컨트롤러에 인쇄된 그림·캐릭터와 무관)

## 3. 하드웨어
- 2인용 아케이드 스틱. 보통 USB로 연결하면 **게임패드 2개**로 잡힌다 (Gamepad API). 기기에 따라 **키보드**로 잡히는 경우도 있어 키 배정 화면에서 둘 다 받는다
- 장치 분류: 새 탭 `arcade` (🕹️ 아케이드 스틱)
- 시작 전 "P1 레버를 위로 → P2 레버를 위로 → 버튼을 순서대로" 배정 (저장해서 다음부터 생략)
- 아케이드 스틱이 없으면 일반 게임패드 2개 또는 키보드 하나(P1 W·A·S·D + F·G·H, P2 방향키 + J·K·L)로 대체

## 4. 조작
| 동작 | P1 (왼다리) | P2 (오른다리) | 결과 |
|---|---|---|---|
| 다리 들기 | 레버 ↑ | 레버 ↑ | 자기 다리를 들어 올림 (드는 동안 한발 서기 → 균형 흔들림) |
| 내딛기 | 레버를 ↑에서 놓거나 ↓ | 같음 | 들어 올린 높이·시간만큼 앞으로 디딤 |
| 보폭 조절 | 레버 ↗ / ↖ | 같음 | 앞/뒤로 크게·작게 디딤 (돌다리 맞추기) |
| 팔 흔들기 | 버튼 1 | 버튼 1 | 내 쪽 팔을 흔들어 반대쪽 기울기 보정 |
| 웅크리기 | 버튼 2 (둘이 같이) | 버튼 2 (둘이 같이) | 낮은 장애물·바람 견디기. 둘이 동시에 눌러야 함 |
| 점프 | 버튼 3 (둘이 0.3초 안에) | 버튼 3 | 구덩이 넘기. 타이밍이 어긋나면 한쪽만 뛰어 넘어짐 |
| 일으키기 | 버튼 연타 (둘이 합산) | 버튼 연타 | 넘어졌을 때 빨리 일어나기 |
| 일시정지 | START | START | |

## 5. 규칙
- 한 다리가 땅에 있어야 다른 다리를 들 수 있다. 두 다리를 동시에 들면 바로 넘어짐
- 같은 다리로 연속 두 번 디디면 그쪽으로 크게 기운다 (번갈아 걷기가 기본)
- 균형 게이지가 한쪽 끝까지 가면 넘어짐 → 일으키기 연타로 회복 (넘어진 횟수만큼 시간 손해)
- 코스 끝 결승선 도착 시간으로 점수. 별 3개 기준 시간은 코스마다 정함
- 체크포인트: 물에 빠지거나 낭떠러지에 떨어지면 마지막 체크포인트에서 다시 시작

### 장애물
| 장애물 | 해결 방법 |
|---|---|
| 돌다리 | 보폭 조절로 돌 위에만 디디기 (물에 디디면 체크포인트로) |
| 빙판 | 보폭을 작게, 천천히. 서두르면 미끄러져 기울어짐 |
| 옆바람 | 둘이 웅크리기 + 바람 반대쪽 팔 흔들기 |
| 낮은 나뭇가지 | 웅크린 채로 걷기 |
| 구덩이 | 동시 점프 |
| 시소 다리 | 다리 가운데를 넘을 때 균형 게이지가 반대로 움직임 |

## 6. 진행·난이도
| 코스 | 길이 | 장애물 | 특징 |
|---|---|---|---|
| 1 들판 | 짧음 | 없음 | 걷기 연습, 화면에 "왼발 → 오른발" 안내 |
| 2 개울 | 보통 | 돌다리 | 보폭 조절 |
| 3 겨울 산 | 보통 | 빙판·옆바람 | 웅크리기·팔 흔들기 |
| 4 숲 | 김 | 나뭇가지·구덩이 | 동시 점프 |
| 5 구름 다리 | 김 | 시소 다리 + 전부 섞기 | 최종 코스 |
- 코스를 하나씩 깨면 다음이 열림 (브라우저에 저장)

## 7. 화면 구성
- 가운데: 옆에서 본 거인과 코스 (가로 스크롤)
- 위: 균형 게이지 (가운데 = 안정, 양 끝 = 넘어짐)
- 아래 왼쪽/오른쪽: P1 / P2 레버·버튼 상태 표시 (다리 색과 같은 색)
- 오른쪽 위: 시간, 넘어진 횟수, 코스 진행률

## 8. 피드백
- 다리 색: P1 주황, P2 청록. 들고 있는 다리는 빛남
- 기울기: 균형 게이지 + 거인 몸 기울기 + 경고음 (점점 빨라짐)
- 넘어짐: 화면 흔들림 + "쿵!" + 먼지. 일으키기 연타 게이지
- 동시 동작 성공(웅크리기·점프): "호흡 척척!" 문구

## 9. 예외 처리
- 레버·버튼 입력이 1초 넘게 없어도 일시정지하지 않음 (가만히 서 있기도 정상 상태)
- **컨트롤러 연결이 끊기면** 자동 일시정지 + "P2 컨트롤러가 빠졌어요" 안내 (기획서 8.4)
- 아케이드 스틱의 레버는 디지털(8방향)이라 "들어 올린 높이"는 누른 시간으로 계산
- 1인 연습 모드: 한 사람이 레버 2개를 양손으로 (또는 키보드 하나로)

## 10. 밸런스 수치 (`config.ts` 초기값)
```ts
liftMaxMs: 600            // 이만큼 이상 들고 있으면 최대 높이
stepBase: 60              // 기본 보폭 (px)
stepBigScale: 1.5         // ↗ 큰 보폭 배율
stepSmallScale: 0.6       // ↖ 작은 보폭 배율
sameLegLean: 0.5          // 같은 다리 연속 사용 시 기울기
oneLegWobble: 0.15        // 한발로 서 있는 동안 초당 흔들림
armRecover: 0.35          // 팔 흔들기 1회 균형 회복량
fallThreshold: 1.0        // 균형 게이지 끝
getUpPresses: 12          // 일으키기 연타 횟수 (둘 합산)
syncWindowMs: 300         // 동시 동작(웅크리기·점프) 허용 시간차
iceSlip: 0.25             // 빙판에서 보폭에 더해지는 미끄러짐
windForce: 0.2            // 옆바람 초당 기울기
starTimesSec: [[40,60,90],[60,90,120],[80,110,150],[100,140,180],[120,160,210]]
```

## 11. 완료 조건
- [ ] 아케이드 스틱(게임패드 2개 / 키보드로 잡히는 경우 모두)의 레버·버튼을 P1/P2로 배정하고 저장할 수 있다
- [ ] P1 레버는 왼다리, P2 레버는 오른다리만 움직인다
- [ ] 번갈아 걷기, 같은 다리 연속 시 기울어짐, 균형 게이지·넘어짐·일으키기가 동작한다
- [ ] 동시 동작(웅크리기·점프)이 허용 시간차 안에서만 성공한다
- [ ] 장애물 6종과 코스 5개가 동작하고 체크포인트에서 다시 시작한다
- [ ] 컨트롤러 연결이 끊기면 자동 일시정지된다
- [ ] 플레이 기록(코스별 시간, 넘어진 위치·원인, 동시 동작 시간차 분포, 플레이어별 입력 수)을 내보낼 수 있다 → 균형·보폭 밸런싱용
- [ ] (사용자 확인 필요) 실제 아케이드 스틱으로 두 사람이 했을 때 웃기고 답답하지 않은 난이도인지

## 12. 정한 것 (2026-11-17, 사용자 결정)
- 추가 모드 없음: 2인 협동 + 1인 연습만 (AI 다리·4인 경주는 넣지 않음)
- 장애물: 코스마다 종류는 위 표대로, **순서·위치는 매번 섞음**
