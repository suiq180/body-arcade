# 박자 붕어빵 (`beat-bungeo`)

> 하드웨어: 🥁 리듬·악기 컨트롤러 (MIDI 키보드 / 드럼 패드) | 원래 조작: 조이스틱 + A 버튼 | 플레이 시간: 하루 장사 약 3분 | 인원: 1인 (2인 협동 옵션)

## 1. 한 줄 소개
흥겨운 장터 음악에 맞춰 **건반·패드를 연주하듯** 반죽 붓고, 속 넣고, 뒤집고, 포장해서 줄 선 손님에게 붕어빵을 파는 리듬 요리 게임.

## 2. 원래 콘셉트에서 가져온 것 / 바꾼 것
- 가져온 것: 붕어빵 틀 여러 개, 4단계 공정(재료 넣기 → 뒤집기 → 포장 → 손님 서빙), 속 재료 선택(팥/슈크림), 뒤집기 타이밍, 픽셀 아트 추억 감성
- 바꾼 것:
  - 조이스틱 선택 + A 버튼 → **틀마다 패드(건반) 하나씩 배정**. 어느 패드를 치느냐 = 어느 틀
  - 모든 공정이 **박자에 맞춰 치는 리듬 입력**. 박자에 정확할수록 붕어빵이 예쁘게 나옴
  - 속 재료는 건반 높이(낮은 음 = 팥, 높은 음 = 슈크림)로 고름

## 3. 하드웨어 배치
- 기본(MIDI 키보드 또는 8패드 컨트롤러):
  | 입력 | 역할 |
  |---|---|
  | 패드/건반 1~4 | 붕어빵 틀 1~4 |
  | 건반 낮은 옥타브 / 패드 5 | 팥 |
  | 건반 높은 옥타브 / 패드 6 | 슈크림 |
  | 패드 7 | 포장 |
  | 패드 8 | 서빙 (손님에게 건네기) |
- 드럼 키트(4패드)만 있는 경우: 틀 2개 모드 + 패드 조합 입력으로 대체
- 시작 전 "화면에 나오는 순서대로 패드를 쳐 주세요"로 키 배정(키 매핑) 저장

## 4. 공정 (한 개 만드는 흐름)
| 단계 | 입력 | 판정 |
|---|---|---|
| 1. 반죽 붓기 | 틀 패드를 **꾹 누르고 있기** (1박) | 누른 길이가 1박에 가까울수록 반죽 양 적당 |
| 2. 속 넣기 | 팥/슈 패드를 박자에 맞춰 치기 | 주문과 같은 속인지 + 박자 정확도 |
| 3. 뒤집기 | 틀 위에 "뒤집기 노트"가 떨어지는 순간 틀 패드 치기 | 너무 빠르면 덜 익음, 늦으면 탐 |
| 4. 포장 | 포장 패드 → 틀 패드 순서로 치기 | 완성된 붕어빵만 포장 가능 |
| 5. 서빙 | 서빙 패드 치기 (맨 앞 손님) | 주문 내용과 맞는지 |
- 틀 4개가 서로 다른 단계에 있으므로, 실제로는 **여러 틀의 노트가 겹치는 연주**가 된다

## 5. 규칙
- 손님은 주문(예: 팥 2, 슈 1)을 들고 줄을 섬. 인내심 게이지가 다 닳으면 떠남
- 붕어빵 품질: 각 공정 판정(PERFECT/GOOD/MISS) 합산 → 황금 / 보통 / 못생김 / 탐
- 판매 금액: 황금 1.5배, 보통 1배, 못생김 0.7배, 탄 것은 판매 불가
- 연속 PERFECT 콤보 시 손님 인내심 회복 + 팁
- 하루(곡 1개) 끝나면 매출 정산, 목표 매출 달성 시 다음 날

## 6. 진행·난이도
| 날 | BPM | 틀 개수 | 특징 |
|---|---|---|---|
| 1 | 85 | 2 | 팥만, 공정 안내 표시 |
| 2 | 95 | 3 | 팥·슈 |
| 3 | 105 | 4 | 단체 손님(주문 4개) |
| 4 | 115 | 4 | 신메뉴: 피자 붕어빵(속 2개 조합 = 화음 입력) |
| 5 | 125 | 4 | 비 오는 날: 손님 인내심 짧음 |

## 7. 화면 구성 (픽셀 아트)
- 가운데: 붕어빵 틀 4개, 각 틀 위로 노트가 떨어지는 세로 레인 (틀 = 레인)
- 오른쪽: 손님 줄과 주문 말풍선
- 왼쪽: 오늘 매출, 목표, 콤보
- 아래: 현재 키 배정 안내 (어떤 패드가 무엇인지)

## 8. 피드백
- 반죽 붓기: 누르는 동안 반죽 차오름, 넘치면 흘러넘치는 연출
- 뒤집기 PERFECT: 붕어빵이 공중 회전 + "착!" 소리 (음악 박자와 같은 음색)
- 탐: 연기 + 까만 붕어빵
- 서빙 성공: 손님 웃음 + 동전 소리

## 9. 예외 처리
- 지연 보정 (공통 리듬 보정 화면, `fruit-bell`과 같은 모듈)
- MIDI 장치 없음: 게임패드(버튼 8개)로 대체 플레이 안내
- 같은 패드 연타로 여러 단계를 한 번에 넘기지 않게, 단계마다 다음 노트가 나올 때만 입력 받음
- 틀이 빈 상태에서 친 입력은 무시 (벌점 없음)

## 11. 완료 조건
- [ ] 키 매핑 화면에서 MIDI 건반·패드를 역할에 배정하고 저장할 수 있다
- [ ] 틀 4개가 독립적으로 붓기 → 속 → 뒤집기 → 포장 단계를 진행한다
- [ ] 각 공정 판정이 박자 기준으로 계산되고 품질에 반영된다
- [ ] 손님 주문·인내심·서빙 판정이 동작한다
- [ ] 피자 붕어빵(화음 입력)이 인식된다
- [ ] 지연 보정 값이 판정에 반영된다
- [ ] 플레이 기록(공정별 판정 분포, 탄 붕어빵 수, 떠난 손님 수, 날별 매출)을 내보낼 수 있다 → BPM·인내심·cookBeats 밸런싱용
- [ ] (사용자 확인 필요) 실제 MIDI 키보드로 쳤을 때 지연이 느껴지지 않는다

## 12. 미정 사항
- 음악: 날마다 곡을 따로 만들지, 한 곡을 템포만 바꿔 쓸지
- 2인 협동(한 명은 붓기·속, 한 명은 뒤집기·포장) 지원 여부
