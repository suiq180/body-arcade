# 말하지 말랬잖아! (`dont-say`)

> 하드웨어: 🎤 마이크 | 원래 조작: 버튼 + 웹캠 몸동작 | 플레이 시간: 한 판 약 4분 | 인원: 1~2인 협동 (마이크 1개 공유)

## 1. 한 줄 소개
고장 난 우주선의 장치들을 **목소리로만** 고친다. 소리를 지르고, 높게 노래하고, 숨죽이고, 정확한 단어를 외쳐야 한다. 그런데 거짓말 로봇의 지시는 반대로 들어야 한다.

## 2. 원래 콘셉트에서 가져온 것 / 바꾼 것
- 가져온 것: 우주선 수리 협동, 장치 6종(엔진·산소·전력·항법·통신·방어) 상태 게이지, 제한 시간, "~하지 마세요(하지만 실제로는 해야 함)" 거짓 지시, 특수 이벤트(거짓말 로봇·중력 반전·버튼 잠금), 성공/폭발 결과
- 바꾼 것:
  - 버튼 담당·몸동작 담당 → **목소리 종류별 담당**. 2인은 "크기·길이 담당"과 "높이·단어 담당"으로 역할을 나눠 같은 마이크 앞에서 협동
  - 모든 미션이 목소리 조작으로 바뀜

## 3. 목소리 조작 종류
| ID | 조작 | 인식 방법 |
|---|---|---|
| `loud` | 크게 소리 지르기 | 음량이 기준 이상 |
| `hold` | 일정 시간 소리 유지 ("아~ 3초") | 음량 유지 시간 |
| `pitch` | 목표 음높이 맞추기 (높게/낮게) | 기본 주파수(피치) 추정 |
| `quiet` | 일정 시간 완전히 조용히 | 음량이 기준 이하 유지 |
| `word` | 정해진 단어 외치기 ("점화!") | 음성 인식 |
| `rhythm` | 정해진 박자로 끊어 소리 내기 ("아! 아! 아!") | 음량 피크 간격 |

## 4. 장치별 미션
| 장치 | 미션 예시 | 쓰는 조작 |
|---|---|---|
| 엔진 | "점화!"를 외치고 3초간 "부웅~" 유지 | word + hold |
| 산소 | 산소 누출! 5초간 완전히 조용히 (소리 나면 누출 증가) | quiet |
| 전력 | 전압 게이지를 목소리 높이로 초록 구간에 맞추고 2초 유지 | pitch |
| 항법 | 별자리 번호 "3, 1, 4" 순서대로 말하기 | word |
| 통신 | 모스 신호 "짧게-짧게-길게" 따라 하기 | rhythm + hold |
| 방어 | 운석 접근 시 크게 소리 질러 방어막 | loud |

## 5. 규칙
- 6개 장치 게이지가 시간이 지나며 줄어듦. 미션 성공 시 해당 장치 회복
- 화면에 지시가 뜨고, **현재 규칙에 따라** 그대로 하거나 반대로 해야 함
  - 정직 로봇(파란 화면): 지시대로
  - 거짓말 로봇(빨간 화면): "~하지 마세요" = 해야 함, "~하세요" = 하지 말고 조용히 기다리기
- 장치 하나라도 0이 되면 경고, 3개가 0이면 폭발(실패)
- 제한 시간(라운드별 45→20초) 안에 모든 장치를 정상(70% 이상)으로 만들면 라운드 성공
- 4라운드 성공 시 게임 클리어. 남은 시간과 장치 상태로 점수

### 특수 이벤트 (무작위)
| 이벤트 | 효과 |
|---|---|
| 거짓말 로봇 | 10초간 모든 지시가 반대 |
| 음높이 반전 | 10초간 높게/낮게 판정 반대 |
| 마이크 잠금 | 3초간 어떤 소리도 인식 안 됨 (그동안 소리 내면 산소 감소) |
| 소음 폭풍 | 배경 소음이 커져서 크게 말해야 함 |

## 6. 진행·난이도
| 라운드 | 시간 | 동시 고장 장치 | 이벤트 |
|---|---|---|---|
| 1 | 45초 | 1 | 없음 |
| 2 | 32초 | 2 | 거짓말 로봇 |
| 3 | 28초 | 2 | + 마이크 잠금 |
| 4 | 20초 | 3 | 전부 |

## 7. 화면 구성
- 가운데: 우주선 단면과 장치 6개 게이지
- 위: 로봇 지시 말풍선 (로봇 색으로 정직/거짓 구분 + 아이콘 모양도 다르게)
- 아래: **음량·음높이 실시간 그래프 상시 표시**, 목표 구간 표시
- 오른쪽 위: 라운드, 남은 시간

## 8. 피드백
- 미션 성공: 장치에 불이 켜지며 게이지 회복 애니메이션
- 실패: 장치에서 불꽃 + 경고음
- 산소 미션 중 소리 감지: 화면에 김 새는 연출

## 9. 예외 처리
- 시작 전 소음 측정 + "가장 낮은 소리 / 가장 높은 소리 내기"로 **개인 음역 보정** (pitch 미션 목표 구간을 사람마다 맞춤)
- 음성 인식(word) 미지원 브라우저에서는 word 미션을 "정해진 길이 소리 내기"로 대체
- 게임 효과음이 마이크로 다시 들어가지 않도록 에코 제거 켜기 + 효과음은 미션 중 작게
- 이어폰 사용 권장 안내

## 11. 완료 조건
- [ ] 목소리 조작 6종이 각각 인식되고 그래프로 표시된다
- [ ] 개인 음역 보정이 pitch 목표 구간에 반영된다
- [ ] 정직/거짓말 로봇 규칙에 따라 판정이 반대로 바뀐다
- [ ] 장치 6종 미션과 게이지 감소·회복이 동작한다
- [ ] 특수 이벤트 4종이 무작위로 발생한다
- [ ] 장치 3개가 0이면 폭발, 전부 정상이면 라운드 성공
- [ ] 음성 인식 미지원 시 대체 미션으로 플레이 가능하다
- [ ] 플레이 기록(미션별 성공률, 조작별 인식 실패율, 라운드별 남은 시간)을 내보낼 수 있다 → 게이지 감소 속도·판정 범위 밸런싱용
- [ ] (사용자 확인 필요) 노트북 내장 마이크로 2명이 같이 해도 플레이 가능하다

## 12. 미정 사항
- 2인 역할 분담을 화면에서 어떻게 표시할지 (미션마다 담당자 색 표시 등)
- 원래 제목 "누르지 말랬잖아!" 를 유지할지, 바뀐 조작에 맞춘 "말하지 말랬잖아!" 로 갈지 (현재 문서는 후자)
