# 귀신도 편의점에 옵니다 (`ghost-store`)

> 하드웨어: 🥽 VR·MR 헤드셋 + 양손 컨트롤러 | 원래 조작: 화면 버튼 3개 | 플레이 시간: 하루(밤) 약 8분, 스토리 7일 | 인원: 1인

## 1. 한 줄 소개
심야 편의점 계산대에 직접 서서, 다가오는 손님을 **가까이 들여다보고** 사람인지 귀신인지 가려내는 VR 공포 관찰 게임.

## 2. 원래 콘셉트에서 가져온 것 / 바꾼 것
- 가져온 것: 손님 관찰 → 계산하기 / 퇴치하기 / 관찰하기 판단, 멘탈(체력) 시스템, 매출, 하루 정산, CCTV, 업그레이드(CCTV 증설·부적 스캐너·보안 조명), 특수 이벤트(가짜 손님·이상한 요구·같은 손님 반복), 다중 엔딩, 스토리·무한 모드
- 바꾼 것:
  - 손님 정보 패널(말투·시선·행동 체크 표시)을 없애고, **플레이어가 직접 단서를 찾는다**: 얼굴을 가까이 보기, 상품 바코드 확인, 거울·CCTV에 비치는지 보기
  - 버튼 3개 → **손 행동 3가지**: 바코드 스캐너로 찍기(계산) / 부적 내밀기(퇴치) / 손전등 비추기(관찰)
  - MR 모드: 내 방 책상을 계산대로 사용 (선택)

## 3. 조작
| 행동 | 입력 | 결과 |
|---|---|---|
| 계산하기 | 오른손으로 스캐너 집어 상품에 대고 트리거 | 상품을 모두 찍고 "계산 완료" 버튼을 누르면 손님이 나감 |
| 퇴치하기 | 왼손 부적을 손님 쪽으로 내밀고 트리거 유지 1초 | 귀신이면 소멸 + 보상, 사람이면 항의 후 이탈 + 페널티 |
| 관찰하기 | 손전등 집어 비추기 | 빛을 비춘 부위의 숨은 단서 표시 (단 비추는 동안 시간이 빨리 감) |
| CCTV 보기 | 고개를 왼쪽 위 모니터로 돌리기 | CCTV 화면 확대 |
| 대화 | 손님이 말할 때 고개 끄덕/젓기 | 일부 손님은 반응에 따라 행동이 달라짐 |

## 4. 단서 시스템
손님마다 단서 0~3개. 귀신은 최소 1개, 사람은 "착각 단서"가 있을 수 있다.
| 단서 | 확인 방법 |
|---|---|
| 그림자가 없음 | 바닥을 내려다보기 |
| CCTV·거울에 안 비침 | 고개 돌려 CCTV 확인 |
| 유통기한 수십 년 지난 상품 | 스캐너 화면의 날짜 |
| 손이 반투명 / 뒤틀림 | 손전등으로 손 비추기 |
| 같은 말 반복 | 대화 듣기 |
| 시선이 나를 안 봄 | 손님 얼굴 가까이 보기 |
| 부적 스캐너 반응 (업그레이드 후) | 스캐너로 손님을 찍기 |

## 5. 규칙
- 하루 = 밤 10시~새벽 4시 (게임 시간, 실제 약 8분). 손님 약 20~30명
- 멘탈 5칸. 귀신을 계산해 주면 -2, 사람을 퇴치하면 -1 + 매출 감소, 0이 되면 그날 실패
- 계산 시 상품 가격만큼 매출. 귀신 퇴치 시 보너스
- 하루가 끝나면 정산 화면 (근무 시간, 방문 손님, 정상/귀신 수, 정확도, 매출)
- 매출로 업그레이드 구매
  | 업그레이드 | 효과 |
  |---|---|
  | CCTV 증설 | 매장 구석 사각지대 추가 확인 |
  | 부적 스캐너 | 스캐너로 손님을 찍으면 귀신 반응 (하루 3회) |
  | 보안 조명 | 귀신 출현 확률 감소, 그림자 단서가 더 잘 보임 |
- 7일차까지 선택·정확도·업그레이드에 따라 엔딩 4종 (평범한 알바생 / 귀신 단골 / 폐점 / 진실)

## 6. 진행·난이도
| 날 | 귀신 비율 | 특징 |
|---|---|---|
| 1 | 15% | 단서 2~3개, 튜토리얼 |
| 2~3 | 25% | 가짜 손님(사람처럼 행동하는 귀신) 등장 |
| 4~5 | 30% | 같은 손님 반복 이벤트, 단서 1개짜리 귀신 |
| 6~7 | 35% | 정전 이벤트(손전등만으로 관찰), 스토리 손님 |
- 무한 모드: 날이 지날수록 비율 증가, 기록 = 버틴 날 수

## 7. 공간 구성
- 플레이어는 계산대 안쪽에 **서 있거나 앉은 자세로 고정** (이동 없음 → 멀미 최소화)
- 정면: 계산대와 출입문, 왼쪽 위: CCTV 모니터, 오른쪽: 스캐너·부적·손전등 거치대
- 왼손 손목: 시계(게임 시간), 멘탈, 매출

## 8. 공포 연출 가이드
- 깜짝 놀래기(점프 스케어)는 하루 최대 2번
- 귀신 공격 연출은 정면에서만, 시야를 완전히 가리지 않기
- 설정에서 "순한 맛" 모드: 귀신 외형 덜 무섭게, 소리 작게

## 9. 예외 처리
- 추적 범위 이탈 시 일시정지
- 손님이 계산대 앞에 너무 오래 있으면(60초) 자동으로 떠남 = 관찰 실패 (멘탈 변화 없음, 매출 없음)
- 컨트롤러 배터리 부족 경고를 손목 UI에 표시

## 10. 플랫폼
- 1차: WebXR + Three.js (퀘스트 브라우저). 손님 모델·매장 에셋이 많아 용량이 커지면 **유니티 빌드 (퀘스트 앱)** 로 전환 검토
- 에셋은 직접 제작 또는 사용 허가가 있는 것만

## 11. 밸런스 수치 (`config.ts` 초기값)
```ts
nightRealMinutes: 8
customersPerNight: [20, 30]
ghostRate: [0.15, 0.25, 0.25, 0.30, 0.30, 0.35, 0.35]
mentalMax: 5
penaltyServeGhost: -2
penaltyBanishHuman: -1
banishHoldMs: 1000
flashlightTimeScale: 2.0  // 비추는 동안 게임 시간 배속
customerTimeoutSec: 60
falseClueRate: 0.2        // 사람에게 착각 단서가 붙을 확률
upgradePrice: { cctv: 50000, scanner: 80000, light: 30000 }
scannerUsesPerNight: 3
jumpScareMaxPerNight: 2
```

## 12. 완료 조건
- [ ] 계산·퇴치·관찰 세 가지 손 행동이 각각 동작한다
- [ ] 단서 7종이 해당 확인 방법으로만 드러난다
- [ ] 멘탈·매출·하루 정산이 규칙대로 계산된다
- [ ] 업그레이드 3종이 다음 날부터 효과를 낸다
- [ ] 7일 진행 후 조건에 따라 엔딩 4종 중 하나가 나온다
- [ ] 무한 모드가 동작한다
- [ ] 순한 맛 모드 설정이 있다
- [ ] 플레이 기록(손님별 정답, 플레이어 판단, 판단까지 걸린 시간, 확인한 단서)을 내보낼 수 있다 → 단서 난이도·귀신 비율 밸런싱용
- [ ] (사용자 확인 필요) 퀘스트에서 프레임 저하 없이 8분 플레이된다

- 스토리 손님 대본과 엔딩 조건 세부
